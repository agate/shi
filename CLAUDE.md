# shi

Classical Chinese poetry turned into pictures and short films with AI. Part of Hong, Hao's site:
served at https://honghao.me/shi/ as a GitHub Pages project page of `agate/shi`, under the custom domain
set on `agate/agate.github.io`.

Nothing is decided yet about the stack or the AI pipeline. Ask before choosing one.

## Rules carried over from honghao.me

Read `~/workspaces/honghao.me/CLAUDE.md` (repo `agate/agate.github.io`) before building any page. In short:

- **Look:** near-white ground, ink-black hairlines, numbered sections, isometric line-art illustrations
  generated by code (never hand-drawn SVG paths, emoji or icon libraries).
- **Fonts:** English headings Instrument Serif, body Inter, metadata JetBrains Mono. **Chinese: LXGW WenKai
  (霞鹜文楷)**, loaded from jsDelivr (`lxgw-wenkai-webfont@1.7.0`, regular + bold), not Google Fonts.
- **Languages:** every visible string in both English and Chinese, switched by an EN / 中 toggle
  (`lang="en"` / `lang="zh"` siblings; the `localStorage` key `lang` is shared across honghao.me).
  Never mix languages in one string. Poems themselves stay in their original Chinese.
- **Author name:** `Hong, Hao` (surname first, with the comma) in both languages.
- **Links home:** every page's footer links back to the main domain with a relative `href="/"`; never
  hard-code `https://honghao.me/`.
- **Commits:** author `agate <agate.hao@gmail.com>`. This machine's SSH key only pushes to the company
  org, so `origin` uses HTTPS with `gh auth git-credential` (already set in `.git/config`).
